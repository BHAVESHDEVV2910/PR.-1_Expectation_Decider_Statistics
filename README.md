# 📊 Expectation Decider – Student Performance Probability Analysis

## 📌 Project Overview

**Expectation Decider** is a Python-based data analysis and probability project that uses student performance data to understand different probability concepts and relationships between academic factors.

The project analyzes student study hours, attendance, group discussion participation, and final examination results to demonstrate practical applications of probability and statistics.

Using **Python, Pandas, NumPy, and Matplotlib**, the project performs probability calculations, creates probability distributions, analyzes relationships between variables, and visualizes overlapping events using a Venn diagram.

The project is designed as a practical learning project to understand how mathematical probability concepts can be applied to real-world datasets.

---

# 🎯 Project Objectives

The main objectives of this project are:

- Understand basic probability concepts using real dataset observations.
- Calculate the probability of passing and failing an exam.
- Calculate the probability of students studying more than 10 hours and failing.
- Understand empirical and theoretical probability.
- Create a probability distribution for students passing an exam.
- Calculate mean and variance of a probability distribution.
- Analyze relationships between study hours and attendance.
- Create a Venn diagram to visualize overlapping events.
- Build a contingency table for group discussion and exam results.
- Calculate joint probability.
- Calculate marginal probability.
- Calculate conditional probability.
- Analyze whether two events are independent or dependent.
- Understand mutually exclusive events.
- Apply Bayes’ Theorem to academic performance data.
